# Veloura Escapes - Luxury Travel Experience Brand

A stunning, modern luxury travel website built with React, Vite, and Tailwind CSS featuring advanced animations and premium design.

## 🌟 Features

### Home Page
- **Hero Section**: Full-screen hero with video background and animated text
- **Horizontal Scrolling Destinations**: Interactive cards with smooth scrolling
- **Why Choose Us**: Premium feature showcase with hover effects
- **Split Layout Experience**: Scroll-triggered image changes with sticky text
- **4-Step Process**: Animated timeline showing the journey
- **Testimonials**: Customer stories with star ratings
- **CTA Section**: Compelling call-to-action with animations
- **Footer**: Comprehensive navigation and social links

### Destination Page
- **Hero Section**: Stunning destination hero with metadata badges
- **Image Gallery**: Interactive gallery with image selection
- **Experience Breakdown**: Day-by-day timeline with highlights
- **Inclusions**: Comprehensive list of luxury amenities
- **Pricing**: Clear pricing display with features
- **Inquiry Form**: Customizable experience request form
- **Final CTA**: Strong conversion-focused closing

## 🎨 Design Features

### Advanced Animations
- **Scroll Reveal**: Elements animate into view as you scroll
- **Hover Effects**: Cards scale and transform on hover
- **Parallax Scrolling**: Background images move at different speeds
- **Sticky Elements**: Text stays fixed while images change
- **Smooth Transitions**: All interactions use smooth CSS transitions

### Premium Styling
- **Luxury Color Palette**: Gold (#D4AF37), Dark (#1a1a1a), Cream (#FAF7F0)
- **Typography**: Playfair Display (serif) for headers, Inter (sans-serif) for body
- **Responsive Design**: Fully responsive across all devices
- **Modern UI**: Clean, minimalist design with attention to detail

## 🛠️ Technology Stack

- **React 18**: Modern React with hooks and functional components
- **Vite**: Fast development server and build tool
- **Tailwind CSS**: Utility-first CSS framework
- **Framer Motion**: Advanced animation library
- **Lucide React**: Modern icon library
- **React Router**: Client-side routing

## 🚀 Getting Started

### Prerequisites
- Node.js 16+ installed
- npm or yarn package manager

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd veloura-escapes
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`

### Building for Production

```bash
npm run build
```

The built files will be in the `dist` directory.

## 🎨 Customization

### Colors
The theme uses a luxury color palette defined in `tailwind.config.js`:
- `veloura-gold`: #D4AF37
- `veloura-dark`: #1a1a1a  
- `veloura-cream`: #FAF7F0

### Typography
- Headers: Playfair Display (serif)
- Body: Inter (sans-serif)

### Animations
Custom animations defined in `tailwind.config.js`:
- `fade-in`: Smooth fade in effect
- `slide-up`: Slide up from bottom
- `float`: Gentle floating animation
